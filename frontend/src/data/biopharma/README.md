# 生物医药研究数据

本目录是“生物医药”一级板块的可持续更新底稿，页面通过通用板块路由 `/sectors/ai-pharma/:tag` 渲染，不另建九套重复页面。

- `sector.ts`：9 个 Tag 的结构化研究正文、表格与引用入口。
- `assets.ts`：统一药物资产卡、临床/监管催化剂和失败复盘库。
- `sources.ts`：参考资料索引；来源记录机构、文献日期、访问日期、类型和 URL。
- `types.ts`：医药数据字段约束。

维护规则：

1. 所有阶段按“药物 + 适应症 + 地区”记录，并同步 `asOf`。
2. 临床数字必须说明人群、线数、剂量、联合方案、对照和数据截止日。
3. BD 必须拆分首付款、近期付款、研发/销售里程碑、上限、分成和区域；上限不得记为收入。
4. 未核实字段保留“暂无可靠公开数据”，不得按同靶点或公司宣传补齐。
5. 来源优先级：监管/临床登记/论文/交易所公告 > 公司新闻稿 > 第三方资料。
