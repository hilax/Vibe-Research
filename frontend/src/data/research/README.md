# AI基础设施与商业航天统一研究库

本目录为 `AI算力 / HBM / 光互联 / 商业航天` 四个一级板块提供共用、可增量维护的数据底座。

- `types.ts`：来源、四证链、四类资产卡、上市公司映射、催化剂、失败复盘和跨板块关联 Schema。
- `sources.ts`：统一参考资料索引。每条来源同时记录发布日期、事件日期、数据期间、访问日期、证据等级和交叉验证状态。
- `catalog.ts`：结构化产品/项目卡、公司映射、催化剂、失败复盘和关联边。
- 各板块的长文放在同级独立目录，页面组件只读取结构化内容，不硬编码研究正文。

维护约束：

1. `null` 表示没有可靠公开数据，不用估算值补空。
2. 标准/样品/送样/认证/小批量/批量/系统出货分开记录。
3. `technology / customer / capacity / financial` 四证链分别展示；任何致命短板不被平均分掩盖。
4. D/E级来源不得成为绿档结论的唯一依据。
5. 规划星座、获批、制造、发射、入轨、正常运营和付费数量永远分栏。
